# agent-dev-kit

Плагин Claude Code для проектов, которые разрабатываются ИИ-агентами.
Даёт быструю инициализацию проекта и процесс, при котором человек читает
спеки, планы и тесты — а качество кода обеспечивается механически.

## Принцип

Качество нельзя «попросить» инструкциями — его нужно навязать. Три слоя,
по убыванию надёжности:

1. **Детерминированные гейты (хуки)** — код не проходит дальше, пока не
   пройдут typecheck / lint / тесты. Модель не может их уговорить.
2. **Агенты-ревьюеры** — чистый контекст, чек-лист, режут раздутый код.
3. **Инструкции и скиллы** — задают процесс, но контролем не являются.

## Процесс

```
Идея → SPEC → PLAN (декомпозиция на атомарные задачи)
     → апрув плана человеком → GitHub milestone + issues
     → задачи по одной: ветка → тесты → код → гейты → PR → ревью-агент
     → человек читает спеку, тесты и вердикт ревьюера → merge
```

## Контракт команд

Плагин мультистековый: хуки не знают стека проекта и зовут стандартные
скрипты `scripts/check`, `scripts/test`, `scripts/fix`, которые обязан
иметь каждый проект. Подробности: [docs/contract.md](docs/contract.md).
Реализации под конкретный стек генерируются при инициализации проекта.

## Состав

```
.claude-plugin/   манифест плагина и marketplace для локальной установки
hooks/            гейты: PostToolUse→check, Stop→test, PreToolUse→запреты
docs/contract.md  контракт команд проекта
commands/         (фаза 2) /project-init, /spec, /plan, /work
agents/           (фаза 3) planner, reviewer
skills/           (фаза 2–3) декомпозиция, TDD, ADR, выбор стека
templates/        (фаза 2) base, nextjs, nestjs, python-service, ...
```

## Установка (локально)

В Claude Code:

```
/plugin marketplace add /Users/a.yalaev/Developments/agent-dev-kit
/plugin install agent-dev-kit@agent-dev-kit
```

Плагин безопасен вне «своих» проектов: если контрактных скриптов нет,
хуки молча пропускают проверки.
